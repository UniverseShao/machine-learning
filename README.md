5.JAMA子刊复现：COX回归结合SHAP方法解析特征对生存预测的影响  
本章节将cox模型和shap方法结合，使得又可以得到cox模型对结果的解释即每个单个具体变量带来的风险，又可以利用shap对模型进行解释，从而获得哪些变量是贡献最大的  
同时本章节解释了为什么shap值解释模型判断特征变量是保护因素还是危险因素应该看趋势而不是看mean(shap)也不是看mean(|shap|),mean(shap)没有什么意义，mean(|shap|)可以体现贡献程度的大小，也不能反应趋势，通过散点shap图后者小提琴shap图可以判断特征变量具体是保护因素还是危险因素，并和cox模型本身进行互补解释  
比如房颤模型中  
cox模型解释有高血压的相比没有高血压的人房颤风险增加多少，有糖尿病的相比没有糖尿病的房颤风险增加多少，shap解释则可以说明到底是有无高血压对房颤的发生贡献大，还是有无糖尿病对房颤的发生贡献大，从而实现互补
